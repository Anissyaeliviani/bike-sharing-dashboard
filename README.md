# Proyek Analisis Data: Bike Sharing Dataset

## Deskripsi

Proyek ini bertujuan menganalisis pola penyewaan sepeda berdasarkan waktu, jenis hari, musim, dan kondisi cuaca.

## Struktur Folder

- `Dashboard/dashboard.py`: kode aplikasi dashboard Streamlit.
- `Dashboard/main_data.csv`: dataset untuk dashboard.
- `Data/day.csv`: dataset penyewaan harian.
- `Data/hour.csv`: dataset penyewaan per jam.
- `Proyek_Analisis_Data_Bike_Sharing.ipynb`: notebook analisis data.
- `requirements.txt`: daftar library yang digunakan.

## Cara Menjalankan Dashboard

1. Instal library:
   `python -m pip install -r requirements.txt`
2. Jalankan aplikasi:
   `python -m streamlit run Dashboard/dashboard.py`
3. Buka alamat lokal yang muncul di terminal.
